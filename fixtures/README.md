# Local test pages

Small pages for developing the layer without a benchmark environment.
Each one shows a case from the proposal:

- `checkout.html`: a form, including a field named only by its placeholder and hidden text.
- `sales_chart.html`: a chart drawn on a canvas, which the accessibility tree cannot describe.
- `inbox.html`: a dialog that covers the page, and icon-only buttons with no names.

These are examples; add, change, or remove them as the team needs.
